# Demo Scene - Ponte Minecraft Unity

Esta sample contém uma cena pronta:

- `Demo.unity` - cena com chão, luz, BridgeManager e UI
- Como abrir: Package Manager > Ponte > Samples > Demo > Import

Ou crie manualmente:
1. Cena vazia
2. GameObject > Ponte > Minecraft Bridge Manager
3. Adicione um Plane como chão
4. Directional Light
5. Play!

Controles:
- Clique em blocos para pintar/deletar
- Q/E ou Espaço/Ctrl sobe/desce
- Botão direito + mouse rotaciona câmera
- Painel OnGUI no canto superior esquerdo (aparece se não houver Canvas)
